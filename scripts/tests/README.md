# חליפות בדיקה — יום הערכה

כל החליפות מדברות עם שרת חי דרך ה-API. **תמיד להריץ על בסיס נתונים זמני**, לא על `data/assessment.db`.

## איך מריצים

```bash
# 1) שרת על DB זמני
cd ~/Desktop/מבחנים\ ליום\ הערכה/app
DB_PATH=/tmp/test.db EXAMINER_PASSWORD=demo123 INTERVIEWER_PASSWORD=iv123 PORT=3000 node server.js &

# 2) חליפה (מתיקיית הבדיקות)
cd scripts/tests
node fixes_test.js
```

לפני כל הרצה: `rm -f /tmp/test.db*` (DB נקי) + `lsof -tiTCP:3000 -sTCP:LISTEN | xargs kill`.

## מה כל אחת בודקת

| קובץ | מה |
|---|---|
| `simday.js` | **סימולציית יום מלא** — הקמה → הרשמת בוקר → שיבוץ ריאיונות+מראיינים → פתיחה → כל הסבבים → סיום. `ROUNDS=5 N=12 node simday.js` (להריץ גם 4 ו-3). מקציב `⌈N/ROUNDS⌉` מראיינים ובודק קיבולת + אפס חפיפות. |
| `fixes_test.js` | 24 טענות: שער המבחן (הרשמה→פתוח), ריאיון בלי מקצועות, חסימת חזרה לשלב הרשמה, חפיפות מראיינים, אזהרת קיבולת, בריפים, ניהול ימים. |
| `round3_test.js` | בריפים עם **שמות מעוותים** (גרשיים / אות סופית / שם אמצעי / טעות הקלדה / לא-קיים / כפילות), `exam_ended` פר-יום, הודעת סיום, `save-day`, ו**שרידות הצילום אחרי מחיקת היום**. |
| `round4_test.js` | בחירת מקצועות **בזמן סבב שרץ** (הנבחן מקבל פרק מיד), חסימת יום סגור, ארכיון + חוברת Excel רב-גיליונות. |
| `round5_test.js` | **שעון הסבב** — שהמנהל, המראיין והנבחן שהגיש רואים את *אותו* מספר (`computeRoundTimer`), שהשהיה כללית עוצרת גם אותו ומחזירה את הזמן, ושאיפוס סבב מנקה אותו. בנוסף: **«סיים סבב» מדווח בשמות מי לא הגיש** והתשובות החלקיות שלהם שורדות. |
| `monday_test.js` | **שליחה ישירה למאנדיי** — רץ מול **שרת מאנדיי מדומה** שהחליפה מרימה בעצמה, אז אין צורך בטוקן, אין נגיעה בבורד אמיתי ואין עלות. הטענה החשובה: **רק העמודות שמופו נשלחות**, וערך ריק לא נשלח בכלל (כדי לא למחוק תא קיים). מריצים לבד: `node monday_test.js` |
| `seed_demo.js` | לא בדיקה — זורע נבחני-דוגמה עם תשובות, כדי להסתכל על המסכים. `DB_PATH=/tmp/demo.db node seed_demo.js` |

## מה תקין לראות
כל החליפות מסתיימות ב-`✅`. אם משהו נכשל — הוא מדפיס `✗` עם ההסבר ויוצא בקוד 1.

⚠ `simday.js` ייכשל בכוונה אם אין מספיק מראיינים (`מראיינים × סבבים < נבחנים`) — זו אזהרת הקיבולת עובדת, לא באג.
